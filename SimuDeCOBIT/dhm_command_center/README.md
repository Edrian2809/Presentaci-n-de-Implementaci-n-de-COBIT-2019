# DHM Command Center v4.0

Sistema de Gobierno de I&T // COBIT 2019 · CMMI v3.0 para Distribuidora Huevos Méndez (DHM).

## Requisitos
Instalar dependencias necesarias:
```bash
pip install streamlit
```

## Cómo ejecutar
Desde la raíz del repositorio, ejecutar:
```bash
streamlit run dhm_command_center/app.py
```
